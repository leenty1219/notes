# Rust 语法与数据类型速查

这篇记录日常写 Rust 时最常查的基础语法、数据类型、字符串和控制流。示例默认放在 `src/main.rs` 中运行。

## 变量、可变性与遮蔽

变量默认不可变；需要修改时在绑定处加 `mut`。不可变绑定是默认选择，可让状态变化更容易追踪。

```rust
let name = "Rust";
let mut attempts = 0;
attempts += 1;

const MAX_ATTEMPTS: u32 = 3;
```

`let` 可以遮蔽已有名字，新绑定可使用不同类型；这不同于 `mut` 对原变量赋值：

```rust
let input = "42";
let input: i32 = input.parse().expect("应为整数");
```

输入解析可能失败，业务代码应将 `expect` 换成 `Result` 错误处理。

## 常见类型

- 整数：`i8`/`i16`/`i32`/`i64`/`i128`/`isize` 与对应 `u*`。
- 浮点：`f32`、`f64`；通常优先 `f64`。
- `bool`：`true` 或 `false`。
- `char`：一个 Unicode 标量值，使用单引号，如 `'中'`。
- 元组 `(T, U)`：固定数量、类型可不同的数据。
- 数组 `[T; N]`：固定长度、元素同类型。
- 切片 `[T]`：连续数据的视图，通常通过 `&[T]` 借用。
- `String`/`Vec<T>`：拥有数据、可增长的堆分配类型。

Rust 不会自动做大多数数值类型转换。`as` 可能截断；需要验证转换范围时用 `TryFrom`：

```rust
use std::convert::TryFrom;

let large: u32 = 300;
let small = u8::try_from(large); // Err(TryFromIntError)，不会悄悄截断
```

## 函数、表达式与控制流

函数参数要标类型。函数体最后一个表达式作为返回值，不写分号；写分号后成为语句，结果为 `()`。

```rust
fn area(width: u32, height: u32) -> u32 {
    width * height
}

fn print_area(width: u32, height: u32) {
    println!("面积：{}", area(width, height));
}
```

`if` 是表达式，两个分支必须返回兼容类型：

```rust
let label = if area(3, 4) > 10 { "大" } else { "小" };
```

常见循环：`loop`、`while`、`for`。范围 `1..5` 不含 5，`1..=5` 包含 5。遍历集合优先使用 `for`，避免手写下标。

```rust
for (index, value) in [10, 20, 30].iter().enumerate() {
    println!("{index}: {value}");
}

let result = loop {
    break 42; // break 可以从 loop 返回值
};
```

## 元组、数组与切片

```rust
let point: (i32, i32) = (3, 5);
let (x, y) = point;

let scores = [80, 90, 100];
let top_two: &[i32] = &scores[1..3];
let maybe_first = scores.get(0); // Option<&i32>，不会因越界 panic
```

固定数组下标越界会 panic；输入决定下标时优先 `.get(index)` 并处理 `Option`。切片借用原数据，不拥有副本。

## String 与 &str

`String` 拥有 UTF-8 字节数据，可以增长；`&str` 是借用的字符串切片。只读文本参数通常写 `&str`，调用处既可传字面量，也可传 `&String`：

```rust
fn greet(name: &str) {
    println!("你好，{name}！");
}

let owned = String::from("Rust");
greet("朋友");
greet(&owned);
```

构造和追加：

```rust
let mut message = String::from("hello");
message.push(' ');
message.push_str("Rust");
let combined = format!("{message}!");
```

不能用整数下标访问字符串，因为 UTF-8 字符长度不定，且字形不等于字节。按 Unicode 标量遍历用 `.chars()`，按字节用 `.bytes()`；按用户可见字形处理需使用 Unicode 分段库。

## Vec 与 HashMap

`Vec<T>` 存储可增长的同类型元素：

```rust
let mut values = vec![1, 2, 3];
values.push(4);
if let Some(first) = values.first() {
    println!("第一个：{first}");
}
```

`HashMap<K, V>` 存储键值：

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();
scores.insert(String::from("Alice"), 90);
let score = scores.get("Alice"); // Option<&i32>
*scores.entry(String::from("Bob")).or_insert(0) += 5;
```

`HashMap` 遍历顺序不保证固定。插入拥有的 `String` 会移动其所有权；需要继续使用时可克隆，或重新设计借用/所有权。

## 模式匹配简写

`match` 必须覆盖所有情况，编译器会检查穷尽性。`if let` 用于只处理某个变体：

```rust
let maybe_port = Some(8080);
if let Some(port) = maybe_port {
    println!("端口：{port}");
}

let description = match maybe_port {
    Some(port) => format!("端口 {port}"),
    None => String::from("未配置端口"),
};
```

匹配时注意是否移动了数据。对引用匹配可用 `Some(ref value)`（较少需要，模式语法也支持 `Some(value)` 自动匹配引用结构）；对只读判断，常用 `match &option` 保留原值。
