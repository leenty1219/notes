## 1. 环境与第一个程序

### 安装

推荐使用 rustup 管理工具链。安装后通常包含 `rustc` 编译器、`cargo` 包管理和构建工具，以及 `rustfmt` 格式化工具、Clippy 静态检查工具。

```bash
rustup update
rustc --version
cargo --version
rustup component add rustfmt clippy
```

### 创建与运行

```bash
cargo new hello-rust
cd hello-rust
cargo run
```

Cargo 创建标准项目：`Cargo.toml` 是包配置，`src/main.rs` 是二进制程序入口。库项目可用 `cargo new my-lib --lib`，入口为 `src/lib.rs`。

```rust
fn main() {
    println!("Hello, Rust!");
}
```

`println!` 是宏（末尾有 `!`），不是普通函数。宏可以在编译期展开成代码。

## 2. 变量类型与基本语法

### 不可变与可变

Rust 变量默认不可变，使用 `mut` 明确允许修改。这让数据变化更醒目，也帮助编译器检查意外修改。

```rust
let name = "Rust";
let mut count = 0;
count += 1;
// name = "Go"; // 编译错误：不可变变量不能重新赋值
```

`const` 是编译期常量，必须标注类型，不能用 `mut`：

```rust
const MAX_RETRIES: u32 = 3;
```

`let` 允许遮蔽（shadowing）：重新声明同名变量。遮蔽可以改变类型，`mut` 赋值则不能改变类型。

```rust
let text = "42";
let text = text.len(); // 新变量，类型变为 usize
```

### 常见标量类型

- 整数：`i8`、`i16`、`i32`、`i64`、`i128`、`isize`；无符号版本为 `u8` 到 `u128`、`usize`。
- 浮点数：`f32`、`f64`（默认通常推断为 `f64`）。
- 布尔：`bool`，值为 `true` 或 `false`。
- 字符：`char`，是 Unicode 标量值，使用单引号，例如 `'中'`；一个 `char` 不等于一个 UTF-8 字节。

整数类型溢出在调试构建中通常会触发检查；发布构建的普通整数运算可能按补码规则回绕。需要明确语义时使用 `checked_add`、`wrapping_add`、`saturating_add` 等方法。

### 类型转换

Rust 不会自动进行大多数数值类型转换，显式使用 `as`：

```rust
let small: u8 = 10;
let larger = small as u32;
```

`as` 转换可能截断或改变数值含义。处理外部输入或大范围整数时应验证范围，或使用 `TryFrom`/`try_into` 获取可失败的转换。

### 元组与数组

```rust
let point: (i32, i32) = (3, 5);
let x = point.0;
let (x, y) = point;

let values: [i32; 3] = [10, 20, 30];
let zeros = [0; 4]; // 四个 0
let first = values[0];
```

数组长度属于类型的一部分，固定不变；越界访问会 panic。长度可变的集合通常使用 `Vec<T>`。

## 3. 函数与控制流

函数使用 `fn` 定义，参数必须写类型。Rust 用最后一个表达式作为返回值，表达式通常不加分号；加分号会变成语句，结果为 `()`。

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn log_message(message: &str) {
    println!("{message}");
}
```

`if` 是表达式，分支返回值类型必须一致：

```rust
let number = 7;
let description = if number % 2 == 0 { "偶数" } else { "奇数" };
```

循环形式包括 `loop`、`while`、`for`。`loop` 可通过 `break value` 返回结果；遍历集合时优先使用 `for`：

```rust
for number in 1..=5 { // 包含 5
    println!("{number}");
}
```

`1..5` 不包含 5，`1..=5` 包含 5。循环标签可用于从外层循环 `break 'outer` 或 `continue 'outer`。

## 4. 常用复合类型

### 元组

将不同类型的有限个值组合起来，字段通过 `.0`、`.1` 访问，也可解构。空元组 `()` 表示没有有意义返回值的单元类型。

### 数组与切片

数组 `[T; N]` 拥有固定长度；切片 `[T]` 是连续元素的视图，通常通过引用使用为 `&[T]` 或 `&mut [T]`。切片本身不拥有数据。

```rust
let values = [2, 4, 6, 8];
let middle: &[i32] = &values[1..3]; // [4, 6]
```

## 5. String 与 &str

`String` 是拥有所有权、可增长的 UTF-8 字符串；`&str` 是字符串切片/借用视图，常用于函数参数。字符串字面量的类型是 `&'static str`。

```rust
let mut owned = String::from("hello");
owned.push(' ');
owned.push_str("Rust");
let view: &str = &owned;
println!("{view}");

fn greet(name: &str) {
    println!("Hello, {name}");
}
```

`String` 可以借用为 `&str`，所以接收只读文本时通常写 `&str`，调用方可传字面量或 `&String`。字符串拼接：`format!("{} {}", first, second)` 会创建新字符串；`first + &second` 会移动左侧 `String`，初学时 `format!` 更直观。

UTF-8 字符串不能用整数下标取“第几个字符”：字节长度与字符数可能不同，一个可见字形还可能由多个 Unicode 标量构成。遍历字符用 `.chars()`，遍历字节用 `.bytes()`；需要按用户感知字形操作时可使用 `unicode-segmentation` crate。

```rust
for ch in "नमस्ते".chars() {
    println!("{ch}");
}
```

## 6. 结构体枚举与模式匹配

### 结构体

结构体将相关字段组合成一个有含义的数据类型：

```rust
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }

    fn square(size: u32) -> Self {
        Self { width: size, height: size }
    }
}
```

`&self` 是 `self: &Self` 的简写，表示方法只借用实例。`&mut self` 表示可变借用；`self` 表示取得实例所有权。关联函数不接收 `self`，常用于构造，使用 `Rectangle::square(4)` 调用。

`#[derive(Debug)]` 让类型支持调试输出：`println!("{rectangle:?}")`；`{rectangle:#?}` 使用多行格式。

### 枚举与 Option

枚举表达“若干种可能之一”，每个变体可以携带不同数据：

```rust
enum IpAddr {
    V4(String),
    V6(String),
}

let address = IpAddr::V4(String::from("127.0.0.1"));
```

`Option<T>` 表示值可能存在或不存在，标准库定义为 `Some(T)` 或 `None`。Rust 没有可随意解引用的空指针；必须处理缺失情况：

```rust
let maybe_count: Option<i32> = Some(5);
let count = match maybe_count {
    Some(value) => value,
    None => 0,
};
```

常用方法：`unwrap_or(default)`、`unwrap_or_else(|| ...)`、`map`、`and_then`。`unwrap()` 在 `None` 时 panic；适合明确不可能失败的测试或原型代码，不应未经判断用于外部输入。

### match 与 if let

`match` 必须覆盖所有可能情况，可用 `_` 表示其余情况：

```rust
match maybe_count {
    Some(n) if n > 0 => println!("正数：{n}"),
    Some(_) => println!("非正数"),
    None => println!("没有值"),
}
```

只关心一个变体时可以写 `if let Some(n) = maybe_count { ... }`。`let ... else` 适合在不符合条件时提前退出：

```rust
let Some(n) = maybe_count else {
    return;
};
println!("{n}");
```

## 7. 集合与迭代器

### Vec

`Vec<T>` 是堆上可增长的同类型元素集合：

```rust
let mut numbers = vec![1, 2, 3];
numbers.push(4);
let first = numbers.get(0); // Option<&i32>，安全处理越界
```

遍历时，`for item in &numbers` 借用元素；`for item in numbers` 消耗并移动集合。不要在持有元素引用期间修改可能导致重新分配的 vector。

### HashMap

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();
scores.insert(String::from("Blue"), 10);
scores.entry(String::from("Blue")).or_insert(0);
```

`HashMap` 的键和值必须实现 `Hash` 和 `Eq`。插入拥有值会按所有权规则移动值。标准 `HashMap` 遍历顺序不保证稳定。

### 迭代器

迭代器通过 `iter()` 借用遍历、`iter_mut()` 可变借用遍历、`into_iter()` 消耗集合。常见适配器有 `map`、`filter`、`take`、`enumerate`、`zip`；常见消费操作有 `collect`、`sum`、`find`、`fold`。

```rust
let squares: Vec<i32> = (1..=5)
    .map(|n| n * n)
    .filter(|n| n % 2 == 1)
    .collect();
```

许多迭代器操作是惰性的，只有调用消费方法后才真正执行。`collect` 的目标类型有时无法推断，可通过变量类型或 `collect::<Vec<_>>()` 指定。

## 8. 所有权借用与切片

所有权是 Rust 管理内存的核心规则，先记住三条：

1. 每个值有一个所有者。
2. 同一时刻一个值只有一个所有者。
3. 所有者离开作用域时，值被释放。

### 移动与复制

赋值或传参可能移动所有权。`String` 位于堆上，赋值通常移动：

```rust
let first = String::from("hello");
let second = first;
// println!("{first}"); // 编译错误：所有权已移动
```

整数等实现 `Copy` 的简单类型会复制，因此旧变量仍可用。需要复制 `String` 内容时使用 `clone()`，这可能有分配成本；优先考虑借用是否足够。

函数调用遵循相同规则：把 `String` 传入按值参数通常会移动它；函数返回值也可以转移所有权。

### 引用与借用

引用允许使用数据而不取得所有权：

```rust
fn length(text: &String) -> usize {
    text.len()
}

let word = String::from("hello");
let size = length(&word);
println!("{word}: {size}");
```

更通用的只读参数通常用 `&str`，而非 `&String`。可变引用 `&mut T` 允许修改被借用的值：

```rust
fn append_mark(text: &mut String) {
    text.push('!');
}
```

借用规则：同一作用域中，可以有多个不可变引用，或一个可变引用；不可变与可变引用不能同时有效。引用必须始终指向有效数据，这就是禁止悬垂引用的原因。

```rust
let mut value = String::from("a");
let view = &value;
println!("{view}"); // 最后一次使用 view
let changed = &mut value; // 此处不可变借用已结束，可以可变借用
changed.push('b');
```

借用检查器依据引用的最后使用位置判断借用范围（非词法生命周期）。遇到冲突时，先缩短引用使用范围，或把计算结果复制出来，再进行修改。

### 切片

切片借用集合的一段连续区域。字符串切片必须落在 UTF-8 字符边界上，否则运行时会 panic。

```rust
let text = String::from("hello");
let part = &text[0..2]; // "he"
```

对任意 UTF-8 文本，不要假设字节偏移恰好是字符边界。许多场景用 `.chars()` 或字符串搜索方法更安全。

## 9. 生命周期

生命周期描述引用有效的范围。大多数时候编译器可以推断，不需要手写标注。生命周期标注不会延长数据寿命，只表达引用之间的关系。

当函数返回引用且编译器无法判断它来自哪个输入时，需要标注：

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
```

`'a` 表示返回引用至少与两个输入引用中较短的那个有效范围一致。调用者不能在原始数据失效后继续使用结果。

结构体存储引用时也要标注生命周期，保证实例不会比引用的数据活得更久：

```rust
struct Excerpt<'a> {
    part: &'a str,
}
```

生命周期省略规则让常见签名更简洁，例如 `fn first_word(s: &str) -> &str`。不要为每个引用机械添加 `'a`；只在编译器要求表达引用关系时添加。`'static` 表示引用可在整个程序运行期间有效，字符串字面量是典型例子；它不等于“应该把所有数据都设成静态”。

## 10. 闭包

闭包可以捕获环境变量，参数和返回值类型通常由编译器推断：

```rust
let factor = 2;
let multiply = |number| number * factor;
assert_eq!(multiply(4), 8);
```

捕获方式可能是不可变借用、可变借用或取得所有权。`move` 强制闭包取得捕获变量的所有权，常用于把数据交给线程：

```rust
let message = String::from("hello");
let task = move || println!("{message}");
task();
```

三种常见闭包 trait：`Fn` 可多次通过不可变借用调用；`FnMut` 调用时可能修改捕获内容；`FnOnce` 可能消耗捕获值，只保证调用一次。定义接收闭包的泛型函数时可用这些 trait bound。

```rust
fn apply_twice<F: Fn(i32) -> i32>(f: F, value: i32) -> i32 {
    f(f(value))
}
```

闭包不是所有场景都比函数指针更简单：若需要存储多种闭包或动态分发，可考虑 `Box<dyn Fn(...) -> ...>`，并理解动态分发和堆分配的代价。

## 11. 错误处理

Rust 常见错误分为可恢复错误和不可恢复错误。可恢复错误使用 `Result<T, E>`；程序逻辑无法继续时可使用 `panic!`。库代码通常应返回错误给调用者，由应用决定如何处理。

### Result 与 ?

```rust
use std::{fs::File, io::{self, Read}};

fn read_file(path: &str) -> Result<String, io::Error> {
    let mut file = File::open(path)?;
    let mut contents = String::new();
    file.read_to_string(&mut contents)?;
    Ok(contents)
}
```

`?` 在 `Ok(value)` 时取出值继续执行，在 `Err(error)` 时从当前函数提前返回错误。函数返回类型必须能接收该错误（直接相同类型，或可通过 `From` 转换）。`?` 可用于 `Option` 返回类型，但 `Option` 和 `Result` 不能随意混用；可使用 `ok_or`/`ok_or_else` 将 `Option` 转为 `Result`。

```rust
fn parse_age(input: &str) -> Result<u8, std::num::ParseIntError> {
    let age = input.parse::<u8>()?;
    Ok(age)
}
```

### 自定义错误的选择

- 小型应用：`Result<T, Box<dyn std::error::Error>>` 方便快速传播错误。
- 库或长期维护项目：定义清楚的错误类型，说明失败原因；常用 `thiserror` 派生实现。
- 应用程序入口：常用 `anyhow` 汇总上下文并输出错误链。

依赖版本和 API 以 crate 文档为准。不要把 `unwrap()` 当作通用错误处理；它会在错误时 panic，适用于示例、测试断言或确实不可恢复的不变量。

## 12. 泛型与 trait

### 泛型

泛型让函数、结构体、枚举和方法适用于多种类型，同时保留静态类型检查：

```rust
fn first<T>(items: &[T]) -> Option<&T> {
    items.first()
}

struct Pair<T> {
    left: T,
    right: T,
}
```

### Trait

trait 描述一组类型需要提供的行为，类似接口/协议：

```rust
trait Summary {
    fn summarize(&self) -> String;
}

struct Article {
    headline: String,
}

impl Summary for Article {
    fn summarize(&self) -> String {
        format!("文章：{}", self.headline)
    }
}
```

trait 可以提供默认方法。实现外部 trait 与外部类型受孤儿规则约束：通常需要至少有一个是当前 crate 定义的。

### Trait bound

```rust
use std::fmt::Display;

fn announce<T: Summary + Display>(item: &T) {
    println!("{}: {}", item, item.summarize());
}
```

多个约束可以用 `+`，复杂约束可用 `where`：

```rust
fn compare<T, U>(left: &T, right: &U) -> bool
where
    T: PartialOrd + ?Sized,
    U: PartialOrd<T> + ?Sized,
{
    left >= right
}
```

`impl Trait` 可用于参数或返回值简写。返回 `impl Trait` 表示返回一个具体但隐藏的类型；单个函数分支不能返回不同的具体类型，即使它们实现了同一 trait。需要运行时存放不同类型时可用 trait object，例如 `Box<dyn Summary>`。

## 13. 模块包与项目组织

- **包（package）**：由 `Cargo.toml` 描述的构建单元，可包含一个或多个 crate。
- **crate**：Rust 编译的基本单元，可为二进制 crate 或库 crate。
- **模块（module）**：组织代码并控制名称可见性。
- **路径（path）**：定位模块及其中类型、函数等项目。

示意结构：

```text
my_app/
├── Cargo.toml
└── src/
    ├── main.rs
    └── config.rs
```

模块默认私有。用 `pub` 开放项目；子模块可访问父模块部分私有项目，但父模块不能自动访问子模块私有项目。`use` 将路径引入当前作用域，`pub use` 可重新导出路径。

```rust
mod network {
    pub fn connect() {
        println!("connected");
    }
}

fn main() {
    network::connect();
}
```

项目增长后按职责拆分模块，例如 `models`、`storage`、`service`。公开 API 应尽量小而清晰，文档注释使用 `///`。

## 14. 智能指针

智能指针像指针一样间接访问数据，同时带有额外所有权或管理能力。先掌握常见几种：

- `Box<T>`：把值放在堆上，所有权仍唯一；常用于递归类型或明确需要堆分配的场景。
- `Rc<T>`：单线程引用计数共享所有权；不能跨线程安全共享。
- `Arc<T>`：原子引用计数，可在线程间共享所有权；修改通常还需配合锁。
- `RefCell<T>`：单线程运行时借用检查，违反借用规则会 panic。
- `Mutex<T>`、`RwLock<T>`：并发场景下保护共享可变数据。

`Rc<RefCell<T>>` 是单线程共享可变状态的常见组合；多线程对应 `Arc<Mutex<T>>`。优先使用普通所有权和借用，确有共享所有权或运行时借用需求再使用智能指针。

## 15. 测试与文档

测试通常写在代码旁的 `#[cfg(test)] mod tests` 中：

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn addition_works() {
        assert_eq!(2 + 2, 4);
    }
}
```

运行 `cargo test`。常用断言有 `assert!`、`assert_eq!`、`assert_ne!`；预期 panic 可用 `#[should_panic]`。集成测试放在项目根目录 `tests/` 下，每个文件作为独立测试 crate。

文档注释 `///` 支持 Markdown 示例，示例代码也会作为文档测试编译运行：

```rust
/// 将两个数相加。
///
/// ```
/// assert_eq!(my_crate::add(1, 2), 3);
/// ```
pub fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

可运行 `cargo doc --open` 生成并查看文档。

## 16. 常用库与生态入口

选择 crate 时查看维护状态、文档、许可证、MSRV（最低支持 Rust 版本）和依赖规模；在 `crates.io` 或 docs.rs 查阅具体版本 API。

- 异步运行时：Tokio、async-std（根据生态和项目需求选择）。
- 序列化：Serde，常配合 `serde_json`。
- HTTP：Reqwest（客户端）；Axum、Actix Web（服务端框架）。
- 错误处理：thiserror（定义错误类型）、anyhow（应用层错误上下文）。
- 命令行：clap。
- 解析：Nom；适合构建高性能解析器，入门可先用标准库字符串操作。
- GUI：egui（立即模式 GUI）、Tauri（Web 前端 + Rust 后端）；桌面项目可参考 [Pake](https://github.com/tw93/Pake)。
- 跨语言绑定：UniFFI 可用于生成多语言绑定，需根据目标语言和平台确认能力。
- 项目目录：[awesome-rust](https://github.com/rust-unofficial/awesome-rust)。

第三方库 API 会随版本变化，优先以所用版本的 crate 文档为准。

## 17. 工程实践与常用命令

```bash
cargo new app                 # 创建二进制项目
cargo new lib --lib           # 创建库项目
cargo run                     # 编译并运行
cargo check                   # 快速检查类型，不生成最终可执行文件
cargo build                   # 构建
cargo build --release         # 发布构建
cargo test                    # 运行测试
cargo fmt                     # 格式化
cargo clippy                  # 静态 lint 检查
cargo doc --open              # 生成并查看文档
cargo add serde               # 添加依赖（需较新 Cargo；也可编辑 Cargo.toml）
rustup update                 # 更新工具链
```

常见工作循环：`cargo fmt` → `cargo check` → `cargo test` → `cargo clippy`。`Cargo.lock` 锁定具体依赖版本：应用程序通常提交它；库项目是否提交依赖团队发布策略。不要随意手工修改锁文件。

依赖写在 `Cargo.toml` 的 `[dependencies]`，开发依赖放 `[dev-dependencies]`。提交代码前检查依赖许可证和维护情况，避免不必要的大型依赖。

## 18. 并发与异步

### 线程

标准线程 API：

```rust
use std::thread;
use std::time::Duration;

let handle = thread::spawn(|| {
    for i in 1..=3 {
        println!("worker: {i}");
        thread::sleep(Duration::from_millis(10));
    }
});
handle.join().expect("worker thread panicked");
```

`join` 等待线程结束。闭包若使用外部数据，可能需要 `move` 转移所有权，避免引用悬垂。

### 通道通信

`std::sync::mpsc` 表示多生产者、单消费者通道。发送值会把值移动到接收端；`recv()` 阻塞等待，`try_recv()` 立即返回当前结果，遍历 `rx` 会在发送端全部关闭后结束。

```rust
use std::{sync::mpsc, thread};

let (tx, rx) = mpsc::channel();
thread::spawn(move || {
    tx.send(String::from("hello from worker")).unwrap();
});
let message = rx.recv().unwrap();
println!("{message}");
```

如需多个生产者，可克隆 `Sender`。实际应用中要设计好发送端关闭、错误传播和接收端退出行为。

### 共享状态

互斥锁保证同一时刻只有一个线程访问受保护数据，使用后尽快释放锁，避免长时间持锁或锁顺序不一致导致死锁。跨线程共享计数器常见形式是 `Arc<Mutex<T>>`。

并发安全由 `Send` 与 `Sync` 等 trait 约束：简要理解，`Send` 表示所有权可在线程间转移，`Sync` 表示共享引用可在线程间安全使用。通常应相信标准库类型和编译器的约束，不要轻易使用 `unsafe` 绕过检查。

### 异步概念

`async fn` 返回一个实现 `Future` 的值；调用异步函数本身不会立即完成工作，必须由运行时驱动并在合适位置 `.await`。Rust 标准库提供 Future 抽象，但不自带通用异步运行时。Tokio 等运行时提供任务调度、定时器和异步 I/O。

先掌握所有权、闭包和错误处理，再学习 async。异步任务不等于自动并行：它主要擅长等待 I/O 时切换任务；CPU 密集工作通常需要专门线程或并行计算方案。

## 19. 练习项目路线

每个项目都尽量拆成小步：先跑通，再加入错误处理和测试。

1. **猜数字**：输入输出、随机数 crate、循环、解析错误。
2. **文本统计工具**：命令行参数、文件读取、`String`/切片、`Result`。
3. **待办事项 CLI**：struct、enum、模块、JSON 序列化、文件持久化。
4. **简单 HTTP 客户端**：HTTP crate、错误上下文、配置和测试。
5. **多线程日志或任务处理器**：线程、通道、共享状态和退出处理。
6. **小型 Web 服务或 GUI**：在语言基础稳固后学习 Tokio/Axum 或 egui/Tauri。

学习时记录“我为什么这样设计”和遇到的编译错误。Rust 编译器的错误信息通常指出冲突发生位置和可行修复方向。

## 20. 常见问题速查

| 现象 | 常见原因 | 优先检查 |
| --- | --- | --- |
| `value borrowed here after move` | 值的所有权已经移动 | 是否应借用 `&T`、克隆或返回所有权 |
| `cannot borrow as mutable` | 可变性未声明，或存在其他有效借用 | `mut` 与引用最后使用位置 |
| 生命周期错误 | 返回引用可能比源数据活得更久 | 是否应该返回拥有所有权的值；再考虑生命周期关系 |
| `use of moved value` | 非 `Copy` 值被消费 | 函数参数按值接收，或循环消耗了集合 |
| `match` 不完整 | 枚举分支未覆盖 | 补充分支或 `_`，避免隐藏重要情况 |
| 字符串下标 panic | 下标不是 UTF-8 字符边界 | 使用 `.chars()`、`.get()` 或合适的 Unicode crate |
| `unwrap()` panic | `Option` 为 `None` 或 `Result` 为 `Err` | 用 `match`、`?` 或有意义的默认值处理 |
| 闭包无法用于线程 | 捕获值不满足线程安全边界 | 所有权、`Send`/`Sync`，以及是否需 `move` |
| `collect` 类型无法推断 | 目标集合类型不明确 | 标注变量类型或使用 `collect::<Vec<_>>()` |
