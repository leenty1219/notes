# Rust 所有权与借用

所有权不是单纯的语法限制，而是 Rust 决定“谁负责让这块数据保持有效、何时释放”的规则。读编译错误时，先标出每个值的所有者、每个引用的有效范围，通常就能找到问题。

## 所有权移动

每个值有一个所有者；赋值、传参、返回值可能转移所有权。离开作用域时，所有者负责释放值。

```rust
let first = String::from("hello");
let second = first; // String 的所有权移动到 second
// println!("{first}"); // 错误：first 已失效
println!("{second}");
```

整数、布尔、字符等简单类型通常实现 `Copy`，赋值时复制值，原变量仍可用。`String`、`Vec<T>` 等拥有堆数据的类型通常不会 `Copy`。`.clone()` 会复制数据，可能分配内存，不要把 clone 当作所有权问题的默认解法。

函数参数也遵循相同规则：

```rust
fn consume(text: String) {
    println!("{text}");
} // text 在这里释放

fn main() {
    let text = String::from("hello");
    consume(text);
    // text 不再可用
}
```

若调用后还需要使用数据，可借用；若函数确实要交接数据，则按值接收或返回所有权。

## 借用与引用

`&T` 是不可变引用，允许读取而不取得所有权。`&mut T` 是可变引用，允许修改：

```rust
fn byte_length(text: &str) -> usize {
    text.len()
}

fn append_exclamation(text: &mut String) {
    text.push('!');
}

let mut message = String::from("hello");
let length = byte_length(&message);
append_exclamation(&mut message);
println!("{message}, 原长度 {length}");
```

借用规则：在某段引用有效期间，可以有任意多个 `&T`，或一个 `&mut T`；不能同时有读引用和写引用。这避免数据竞争和读写时序不明。

```rust
let mut value = String::from("a");
let read = &value;
println!("{read}"); // read 最后一次使用
let write = &mut value; // 此时读借用已结束
write.push('b');
```

借用范围按引用的实际使用位置确定，不一定延伸到词法作用域末尾。若冲突，尝试缩短引用的使用范围、先完成读取再修改，或把必要的小数据复制出来。

## 可变引用的常见冲突

```rust
let mut names = vec![String::from("A")];
let first = &names[0];
// names.push(String::from("B")); // 可能导致重新分配，first 会悬垂，所以禁止
println!("{first}");
```

修改 `Vec` 可能重新分配底层内存，使旧元素引用失效。把引用最后一次使用提前，再修改集合：

```rust
let mut names = vec![String::from("A")];
let first_len = names[0].len();
names.push(String::from("B"));
println!("长度：{first_len}");
```

## 切片

切片是对一段连续数据的借用，不拥有内容：

```rust
let text = String::from("hello rust");
let word: &str = &text[0..5];
let numbers = [2, 4, 6, 8];
let pair: &[i32] = &numbers[1..3];
```

字符串范围按字节计算，边界必须落在 UTF-8 字符边界，否则会 panic。对未知文本不要随意写 `&text[0..n]`；可用 `.get(0..n)` 安全取得 `Option<&str>`，或通过 `.chars()` 遍历。

函数参数优先选择能表达需要的最小所有权：

- 只读文本：`&str`。
- 只读集合：`&[T]`。
- 要修改调用方的值：`&mut T`。
- 需要保存数据或接管数据：拥有类型 `String`、`Vec<T>` 或泛型 `T`。

## 返回值和所有权

函数可以返回拥有的值，所有权移交给调用方：

```rust
fn make_greeting(name: &str) -> String {
    format!("Hello, {name}")
}

let greeting = make_greeting("Rust");
```

不能返回函数局部变量的引用，因为函数返回后局部变量已被释放。通常应返回拥有的 `String`/`Vec<T>`；只有引用来自有效的输入或其他长寿命数据时，才返回引用并表达生命周期关系。

## 借用检查问题排查

遇到 `moved value`：检查先前哪次赋值/函数调用取得了所有权，决定改为引用、返回值或必要时 clone。

遇到 `cannot borrow as mutable`：检查变量是否 `mut`，是否还存在有效的不可变引用，及是否同时创建多个可变引用。

遇到生命周期错误：检查返回的引用具体指向谁，源数据是否会先于引用失效。不要先随意补 `'static`；多数情况应改变返回值所有权或缩短引用使用范围。

## 所有权设计示例

一个只做查询的函数借用切片，不接管集合：

```rust
fn largest(values: &[i32]) -> Option<i32> {
    values.iter().copied().max()
}

let scores = vec![3, 9, 5];
let max_score = largest(&scores);
println!("scores 仍然可用：{scores:?}; 最大值：{max_score:?}");
```

`copied()` 对 `i32` 复制值，再由 `max()` 返回拥有的 `Option<i32>`，因此返回值不依赖输入集合的生命周期。
