# AI 工具索引

本目录用于记录 AI 编码工具、终端 Agent、协作运行时和相关 CLI 的速查信息。

## 工具速查

| 文件 | 内容 |
| --- | --- |
| [pi.md](pi.md) | pi 启动、会话、编辑器操作、快捷键、模型、工具控制等 |
| [codex.md](codex.md) | Codex CLI 安装、认证、exec、沙箱、审批、参数、会话管理 |
| [claude.md](claude.md) | Claude Code 安装、认证、权限模式、快捷键、斜杠命令、CLI 参数 |
| [copilot.md](copilot.md) | GitHub Copilot CLI 安装、认证、模型、权限、MCP、LSP 等 |
| [kimi.md](kimi.md) | Kimi Code CLI 安装、认证、参数、子命令、MCP、交互功能 |
| [herdr.md](herdr.md) | Herdr 会话、布局、pane、workspace、agent 管理 |
| [omx.md](omx.md) | oh-my-codex 启动、任务队列、团队运行时、工作流关键词 |
| [oh-my-pi.md](oh-my-pi.md) | oh-my-pi 安装、入口、模型角色、工具、关键词、扩展 |

## 使用建议

- 查单个工具命令时，直接进入对应文件。
- 比较工具能力时，优先看 `pi.md`、`codex.md`、`claude.md`、`copilot.md`。
- 涉及多 Agent 协作、pane 管理、任务派发时，看 `herdr.md` 和 `omx.md`。
- 工具配置类内容建议保留命令示例和配置路径，避免只写概念。
